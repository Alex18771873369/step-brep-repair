# DSH 中使用 STEP 曲面修补技能

本教程适用于已经安装并启用本插件的用户。技能名称是 **`step-brep-repair`**，用于协助 AI 分析 `.stp` / `.step` 模型的破面并尝试修补。

> 提醒：这是“AI 工作流程 + 诊断辅助”，不是保证成功的一键补面器。复杂模型可能需要多次调整，也需要在 Creo、SolidWorks、FreeCAD 等目标软件中核对。

## 第一步：设置工作区

1. 打开 DeepSeek Harness（DSH），新建一个会话。
2. 在新会话界面点击**“选择工作区” / 文件夹图标 / 当前工作区名称**；也可在左侧使用“添加工作区”。不同版本的界面位置可能略有不同。
3. 选择一个专门存放本次模型及结果的文件夹；如果还没有，先在文件管理器里新建一个。例如 Windows 可选 `D:\CAD修补\项目A`。
4. 确认 DSH 当前工作区显示为刚选的文件夹。后续用 `@` 引用的**相对路径**通常从该工作区解析。

建议每个任务使用独立文件夹；先备份模型，并告诉 AI 不要覆盖原件。CAD 模型可能包含设计机密，选择工作区和模型服务前请遵守公司的信息安全要求。

## 第二步：把 STEP 模型提供给 AI

二选一：

### 方法 A：先把文件放入工作区（推荐）

1. 在 Windows 文件资源管理器（或 macOS/Linux 文件管理器）中打开第一步选择的工作区。
2. 将 `.stp` 或 `.step` 模型文件**复制**到该文件夹，不要只创建一个无效的快捷方式。
3. 回到 DSH 输入框，输入 `@`，在出现的文件列表中选择你的模型。若看不到文件，可以确认工作区位置、刷新文件列表，或直接在消息中输入相对于工作区的路径，例如 `@外壳.stp`。
4. 文件在子目录时，引用形式例如 `@零件/外壳.stp`；路径包含空格时可使用 `@"外壳 模型.stp"`。

`@外壳.stp` 只是示例，请使用自己的真实文件名。也可使用用户明确提供的绝对路径；不要假定其他人的电脑路径相同。

### 方法 B：通过 DSH 提供文件

1. 点击输入框旁的 **“+”** 或文件相关按钮，按界面提示选择 `.stp` / `.step` 文件；如果当前版本支持文件拖放，也可拖入模型。
2. 看输入框实际出现的是**文件路径引用**还是**上传附件卡片**，确认引用或上传完成后再发送。桌面端可能直接引用文件的原始路径，原文件需持续可读；普通浏览器可能上传为附件，需等待上传完成。不同版本和环境的支持方式可能不同。
3. 不要假设提供给聊天的文件已自动复制到工作区；让 AI 先确认实际可访问的位置。如果 AI 无法读取附件，请改用方法 A，或告诉 AI 可访问的本地文件路径。

## 第三步：选择修补技能

如果安装了 DSH 技能选择器，可以通过按钮选择；未安装选择器时，直接在聊天输入框输入 `/step-brep-repair` 即可。

1. 点击输入框右下角、模型名称旁的 **⚡ 技能选择按钮**。
2. 在技能选择器的搜索框中输入 **`step`** 或 `step-brep-repair`，**搜索时不要输入 `/`**。
3. 点击 **step-brep-repair**。选择后通常会把 `/step-brep-repair` 插入消息输入框。
4. 确认技能手势、模型引用和你的要求都在消息中，再点击发送。

也可以直接在**聊天消息输入框**输入 `/step-brep-repair`，但不要把它误当成技能选择器搜索词。如果搜索不到，先清空搜索、检查插件是否安装且启用，再新建会话；必要时按 DSH 提示重启。若有同名旧技能，还应核对正在加载的来源。

## 第四步：告诉 AI 你想怎么修

复制下面的示例，改成自己的文件名和要求：

```text
/step-brep-repair @外壳.stp
这个 STEP 模型有破面，请检查并尽量修补成封闭实体。
我使用 Creo 打开。请尽量保留原有曲面，不要把整个模型转成三角网格。
允许局部补近似面，但请说明形状变化；另存结果，不要覆盖原文件。
请重新读取结果并检查封闭性，最后给我 STEP 文件。
```

如有加工用途，请额外说明允许的尺寸偏差、公差、关键配合面及不能修改的结构；如果只是视觉或模型演示，也请说明。若不希望安装软件或调用 MCP，也请直接告诉 AI。

## 第五步：配合定位破面

AI 会先检查本机已有的 CAD 工具及可访问接口。如果工具不可用，会说明情况；需要安装 FreeCAD 或配置第三方 MCP 时，应先说明影响并征得你的确认。

如果破面无法从模型中直接定位，AI 可能会请你在 Creo 等软件中：

- 放大破面或粉色边线并截图，最好标明位置；
- 用“分析 / 测量”查看问题点的 XYZ 坐标；
- 说明打开的是原始文件还是哪个修补版本。

坐标点也可能位于边的中间，不必强行选成端点。截图和测量信息能减少误修其他曲面的风险。

## 第六步：下载并复核结果

1. 点击 AI 消息中的修补结果下载链接，保存新的 STEP 文件。
2. 用你的目标 CAD 软件打开**新文件**，检查破面或粉色边线是否消失。
3. 检查软件是否真正识别为实体；必要时核对体积、外形、装配关系、布尔操作及加工尺寸。
4. 如果还有问题，把截图、坐标和打开的文件名一起发回给 AI，要求在该版本基础上继续修。

**“AI 软件报告闭合”不一定等于“Creo 导入后是完整实体”。** 只有在你的目标软件里实际验证后，才可确认满足用途；用于加工前还需检查尺寸与公差。

## 常见问题

**Q：没有 FreeCAD，也能使用吗？**  
可以先让 AI 检查已有 CAD 与接口；如果无法处理，AI 会说明是否需要在征得同意后安装 FreeCAD。安装插件本身不会自动安装 CAD 或 MCP。

**Q：技能会把模型发送到网上吗？**  
本地诊断脚本本身不负责上传模型；但文件上传、远程模型服务、MCP 服务及日志的实际数据流取决于用户的 DSH 配置和使用方式。涉及机密模型时，请先核对公司政策和当前服务配置。

**Q：选择器里搜不到技能？**  
确认插件安装并启用；搜索框输入 `step` 而不是 `/step`。若仍无结果，新建会话或按安装结果提示重启；同时检查是否安装在正确的 DSH profile。
